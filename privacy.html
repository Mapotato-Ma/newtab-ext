隐私政策

适用于 Chrome 扩展「索引卡 · 新标签页」 · 最后更新：2026 年 10 月 14 日
一句话：这个扩展不收集、不上传、不存储你的任何个人数据。
它只做一件事 —— 在本地读取你浏览器里已有的书签，然后把它画成一个新标签页。 没有账号系统、没有服务器、没有统计埋点、没有广告。

扩展做什么

「索引卡」把 Chrome 的书签文件夹渲染成新标签页：左侧竖栏是第 1 层文件夹 （严格按你自己的顺序），右侧是这一组书签的索引卡；子文件夹可以逐层钻取，顶部面包屑显示当前位置。 所有渲染都在你的浏览器本地完成。

收集哪些数据

不收集。具体来说：

  • 不收集、不读取你的浏览历史
  • 不收集、不上传你的书签内容（只在本地内存里读取用于显示）
  • 不收集设备信息、位置、IP、账号信息
  • 不包含任何分析 / 统计 / 崩溃上报 SDK，不发起任何「回家」请求
  • 不出售、不转让任何数据给第三方（因为没有数据可转让）

权限逐条说明

bookmarks 读取你书签栏里的文件夹与网址，用来渲染分组和磁贴。 只读 —— 扩展不会创建、修改、移动或删除任何书签。
favicon 向 Chrome 自己的图标缓存取每个书签的图标。这个缓存就在你本机， Chrome 不会因此把任何信息发给网站。取不到图标时，扩展用书签标题的第一个字作为兜底显示。
storage 保存你的界面偏好（深色/浅色、界面缩放、打开方式、搜索引擎等）。 存在 chrome.storage.sync，也就是 Chrome 自带的账号同步里 —— 数据由 Google 管理、在你自己的设备之间同步，扩展作者看不到，也没有任何服务器接收它。
api.bing.com 仅当你在新标签页的搜索框里输入文字时，把你输入的那段文字发给必应的 搜索建议接口，好把候选词显示在下拉框里。不发送书签、不发送浏览历史。
suggestqueries.google.com 同上，只是换成谷歌的建议接口（当你把搜索引擎切成谷歌时）。 同样是只发你输入的那段文字。

搜索框里输入的字会发给对应的搜索引擎，这是「搜索建议」这个功能本身的要求 —— 和你直接在搜索引擎网站 输入是一样的。如果你想完全避免这一点，不使用搜索框即可，扩展的其余功能不受影响。

远程代码

扩展不包含、不加载任何远程代码。所有 JavaScript 都随扩展一起打包， 更新只能通过 Chrome 应用商店的正式升级流程发生。

数据留存与删除

扩展不持有任何数据，所以没有「删除数据」的流程。卸载扩展后， 存在 chrome.storage.sync 里的界面偏好会被 Chrome 清除； 你也可以随时在 Chrome 的扩展管理页里移除它。

儿童

本扩展不面向儿童，也不收集任何年龄相关或个人身份信息。

政策变更

如果这份政策有更新，会修改本页顶部的「最后更新」日期。功能上的实质变化会在扩展的版本说明里一并写明。
