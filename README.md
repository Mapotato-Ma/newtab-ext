# 索引卡 · 新标签页

把 Chrome 书签**直接**渲染成新标签页的分组网格。没有账号、没有后端、没有同步逻辑 ——
因为你浏览器里的书签本来就已经在 Chrome 云同步里了，扩展只是把它换个样子显示出来。

## 装进 Chrome（30 秒）

1. 把 `newtab-ext/` 整个文件夹拷到电脑上（任选一个不会挪走的位置，比如 `D:\newtab-ext`）
2. Chrome 地址栏输入 `chrome://extensions`
3. 右上角打开 **开发者模式**
4. 点 **加载已解压的扩展程序** → 选中 `newtab-ext` 文件夹
5. 新开一个标签页 → 应该看到你的书签栏分组

## 判据（第一版过没过就看这一条）

> 新标签页显示的分组 = 你**书签栏**里的一级文件夹；
> 在书签管理器里加一条 / 删一条 / 改个名，回到新标签页**立刻**跟着变。

这条过了，剩下的都是皮肤问题。

## 现在的行为

- **分组**：书签栏下的一级文件夹 = 一个分组；直接丢在书签栏根下的散书签 = 「未分组」（可在设置里关掉）
- **子文件夹（任意层级，0–7 层都收得住）**：左栏永远只列**第 1 层**；
  钻进去后主区始终是**三档**——面包屑 / 当前层的卡片 / 直接子文件夹的入口行。
  子文件夹还会顺带铺开它自己的内容；它再往下有东西时，只在下面缩进一格放一个入口行，
  想看就点进去（面包屑变长一位）。**屏幕上的层级感恒定，不随数据变深**：
  第 7 层和"第 2 层"走的是同一条路，代码里没有为深度写任何特例。
  缩进刻度只画 2 格（再深就靠面包屑，缩进 7 次字会被挤没）；
  面包屑到 4 段以上时中间折成 `…`，点它跳到那一层。
- **图标**：三级降级 —— ① 走 Chrome 自己的图标缓存（`_favicon/`）；② 识别出「没有图标」占位图
  （⚠️ Chrome 找不到图标时**不报错**，会返回一张默认的**灰色地球**，所以得拿一个必然没有图标的地址
  当参照物、缩到 16×16 比对指纹；纯色一坨的图也当没有）；③ 试站点自己的 `/favicon.ico`。
  都不行 → **用书签标题的第一个字**当图标（中文自然取到「工」「综」「少」，英文取首字母大写），
  底色调子由域名算出来（浅/深两套）。**只有滚到跟前的磁贴才去解析图标**，不一次发几百个请求
- **左侧竖栏 = 第 1 层文件夹**（**严格保序**，任何情况都不重排 —— 顺序是你手动排的空间记忆）：
  名称单行省略、计数右对齐等宽、空文件夹**只降透明度不移动不隐藏**、左栏自己滚动、
  超过 40 个文件夹时顶部出现**筛选框**（筛选 ≠ 排序，只藏不合的）。
  `↑` `↓` `←` `→` 切分组（**到头绕回**，`Home`/`End` 跳首尾），`Esc` 返回上一级；
  **记住上次看的分组 + 钻到哪一层**（新标签页每次全新加载，存在 `localStorage` 里）
- **小组预览**：分组里 ≤5 项时，鼠标悬停或键盘聚焦会飘出内容（hover + focus 双通道），
  浮层挂在 `body` 上用 fixed 定位 —— 挂在左栏里会被滚动容器的 `overflow` 裁掉
- **只有磁贴区滚动**：`.page` 高度固定为 `calc(100vh / scale)`，刊头、标签栏、页脚都钉住，
  只有 `.board` 是 `overflow-y: auto`。滚到底也还看得见分组栏。
  （⚠️ flex 子项要写 `min-height: 0`，否则 `overflow` 不生效）
- **打开方式**：设置里可选**新标签页（默认）/ 当前标签页**。磁贴和搜索建议走同一个入口
  `openUrl()`，切了新标签页就给 `<a>` 加 `target="_blank" rel="noopener"`；
  `Ctrl/⌘+点击`、中键两个模式下都是后台新开（`<a>` 的原生行为）
  - ⚠️ **输入框里直接回车走的是表单原生提交，会绕过 `openUrl`**（永远在当前页打开）——
    所以 `submit` 事件里 `preventDefault()` 掉改调 `goSearch()`。五条打开路径都验过：
    磁贴 / 直接回车 / 网络建议 / 第一条「用必应搜索」/ 书签建议
- **搜索**：右上角搜索框，回车直接跳结果页；`Ctrl/⌘+K` 或 `/` 聚焦，`Esc` 退出
  - **搜索引擎**：点输入框**左边的放大镜**在**必应 ⇄ 谷歌**之间来回切（只有这两家）。
    切换会同时改表单 `action`、占位文字、下拉第一行的文案；存在 `storage.sync` 里
  - **建议跟着引擎走**：必应 → `api.bing.com/osjson.aspx`，谷歌 → `suggestqueries.google.com/complete/search?client=firefox`。
    谷歌那家**地区美国 + 英文**（`gl=us&hl=en`），搜索页带同一组参数，两边一致。
    ⚠️ `gl`（结果地区）和 `hl`（界面语言）是**分开的两个开关**：实测 `hl=zh-CN` 加不加 `gl=us`
    拿到的建议完全一样，真正决定建议语言的是 `hl`。现在 `hl=en`（英文建议）
    **只问当前引擎那一家**；取不到（没挂代理、被墙）就只留本地书签匹配 ——
    「故意不跨引擎降级」，用谷歌搜却给必应补全词没意义，反正最后跳 `google.com` 那步照样打不开
  - ⚠️ **两家接口都不带 CORS 头**（带 `Origin` 实测过），所以 manifest 里按域分别申请：
    `api.bing.com` + `suggestqueries.google.com` —— 两个具体域名，不是「所有网站」那种
  - 兼容两种返回格式：`["q",["建议"…]]`（必应 / 谷歌 client=firefox）
    和 `["q",[["建议",0,[]]…]]`（谷歌 client=chrome 的嵌套式）
  - **建议下拉顺序**：① 本地**书签匹配**（最多 4 条，带 favicon 和域名）
    ② 当前引擎的网络建议（最多 8 条）③ `↑` `↓` 选择，回车打开，点也行
  - 本地匹配的优先级：标题开头 > 标题包含 > 网址包含
- **界面缩放**：设置里 90% / 100% / **115%（默认）** / 130% / 150%，`Ctrl/⌘` + `+` `−` 也能直接调。
  实现是 `html { zoom: var(--scale) }` 一个开关，字号、间距、磁贴一起放大；
  `.page` 的 `min-height` 写成 `calc(100vh / var(--scale))` 来抵消，页脚才压得住底
- **点击**：当前标签页打开。`Ctrl/⌘ + 点击`、中键 = 后台新开（这是 `<a>` 的原生行为，没拦）
- **实时**：书签增删改移都会自动重渲染，不用刷新
- **设置**（右上角齿轮）：外观（跟随系统/浅/深）、时间显示（**时:分:秒，默认** / 时:分）、
  图标大小（紧凑/标准/宽松）、是否显示「未分组」

## 文件

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单：`chrome_url_overrides.newtab` 接管新标签页 |
| `newtab.html` / `newtab.css` / `newtab.js` | 界面本体，无构建步骤，改完直接刷新 |
| `mock-chrome.js` | **只在预览时加载**的 `chrome.*` 替身，不进扩展包 |
| `preview.html` | 本地预览页（由 `newtab.html` 加一行注入生成），手机上也能看 |
| `icons/` | 16 / 48 / 128 图标（脚本生成，非扒素材） |

生成预览页（改了 `newtab.html` / 改了任何 js、css 之后都要重跑一次；
带 `?v=` 是为了绕开 webview 的缓存，不然改了没生效会被当成代码没写对）：

```sh
cd newtab-ext
V=$(date +%s)
sed -e "s|<script src=\"newtab.js\"></script>|<script src=\"mock-chrome.js?v=$V\"></script>\n  <script src=\"newtab.js?v=$V\"></script>|" \
    -e "s|href=\"newtab.css\"|href=\"newtab.css?v=$V\"|" newtab.html > preview.html
```

⚠️ 改完代码装回 Chrome 时，要在 `chrome://extensions` 上点一次 **刷新**，
否则 Chrome 用的还是旧代码（新标签页是缓存的重灾区）。

## 为什么这条路线干净

- **不做账号**：书签同步交给 Chrome 自带的
- **不做云**：没有服务器，没有数据库，没有登录
- **配置跨设备**：`chrome.storage.sync` 本身就是跟着 Chrome 账号走的（配额 100KB，存这几项设置绰绰有余）
  → **不建账号也能跨设备同步** —— 这是「不要账号」能成立的关键
- **排序只存本地**：拖拽排序（第二版）写进 `storage.sync`，**不去移动你的书签树**

## 已知环境限制（记录用）

- iSH 上跑不了 `impeccable detect`（自带二进制 `Illegal instruction`）；`impeccable context` 这类 shell 部分正常。
  设计检查目前靠**渲染截图肉眼过两轮**（浅色 + 深色）。
- 预览页里**加载不了远程 favicon**（`minis://` 页面里跨域图片不落地），所以预览看到的多是字母兜底，
  真机上会显示真实图标。

## 0.4.0（2026-10-14）

按 MiniMax 的《文件夹原生约束 · 排版预案》 + 评审结论改的（评审全文：`design/REVIEW-20261014.md`）。

- **左栏导航**替换原来的顶部胶囊栏（21 个分组时胶囊要换行占三行，扫视性差）
- **索引卡**替换原来的小磁贴：图标 + **完整标题（默认不限行数）** + 站点域名。
  标题行数可在设置里收紧成 1/2/3 行
- **钻取式嵌套**（见上），修掉一个真 bug：**旧版只渲染两层，但计数和搜索含全部层级** ——
  `groupSection()` 把第 3 层往后的书签直接丢了，而 `groupTotal()` 在递归计数。
  现在渲染、计数、搜索三条路径用的是同一棵递归树
- 面包屑、子文件夹入口行、`Esc` 返回上一级、空文件夹提示
- 新增 `sync-preview.py`：改完 `newtab.html` 跑一次，`preview.html` 自动跟着更新（含缓存时间戳）

- **原地折叠**：子文件夹入口行左边一个 `▸` 只折叠/展开它自己（不影响你在哪一层），
  点行的其余部分才钻进去 —— 一行两个动作，就分成两个按钮，不塞进同一个点击区。
  折叠状态存 `localStorage`
- **计数口径开关**：设置里可切「含子文件夹（默认）/ 只算本级」。
  ⚠️ 「空文件夹置灰」永远看 `total`（真的什么都没有），不看这个开关 ——
  否则一个只装了子文件夹的组会被显示成 0 项还灰掉
- `sync-preview.py` 现在同时生成 `preview.html`（调试）和 `preview-store.html`（商店截图）
- **每行列数可配 1–4 列（默认 3）**：原来用 `auto-fill` + 最大宽度，宽屏上只排得出两列、右边留一大片死白。
  改成固定列数 + `1fr` 撑满；窗口太窄时由 `@media` 降列兜底（是兜底，不是覆盖用户选择）
- **左栏悬浮预览统一成「所有非空分组都有」**（不再只给 ≤5 项的小组）：
  140ms 延迟（鼠标路过不弹）、标题栏 `组名 + n 项`、有子文件夹先列它们的名字、
  **固定居中 + 毛玻璃背景**（`backdrop-filter`，不支持模糊的环境有实底兜底）、
  两列最多 24 条、面板内部滚动（别再动不动「还有 n 项」）；
  挂在 `body` + `position: fixed`（挂左栏里会被滚动容器的 `overflow` 裁掉）
  ⚠️ **面板不靠 CSS 动画变可见**：Minis 预览 WebView 里 CSS 动画不推进，
    用 `animation` 做淡入会把面板永久卡在 `opacity: 0`（踩过，查了半天）
- **点页面别处关掉设置面板**（`pointerdown` 比 `click` 早一步，手感更跟手）
- **字体大小 / 字重可配**（设置里两项）：字号 6 档 **12 / 13（默认）/ 15 / 18 / 21 / 24**
  —— 上限放到 24px（用户 2026-10-14 要求，原来只到 15.5）。
  **图标也跟着字号走**（用户 2026-10-14 要求「图标的字和大小也要跟着放大」）：
  `--fs-ratio = fs / 13` 由 JS 写到 `:root`，图标尺寸 = `图标基准(--icon-base，随「图标大小」档位) × --fs-ratio`；
  卡片图标、兜底字母、文件夹行的文件夹图标 / 箭头 / 折叠三角、悬浮面板的小图标都按它放大。
  实测 13px → 图标 30px、字母 12.6px；24px → 图标 55.4px、字母 23.3px（同比例）。
  ⚠️ 字放大后**左栏行不能写死高度**：`.ritem` 原来是 `height: 30px`，
  24px 时文字会被顶出去 → 改成 `min-height` + 上下 padding。卡片同理只给 `min-height`（它是下限不是定值）。
  一套基准值：一套基准值 `--fs` / `--fw` 派生各处 ——
  卡片标题与左栏分组名 = `--fs`；子文件夹名与悬浮面板文字 = `--fs-md`（−0.5）；面包屑计数 = `--fs-sm`（−1.5）；
  域名与计数 = `--fs-xs`（−2）。字重同理，文件夹名用 `max(字重, 500)`，免得 400 时导航比正文还轻。
  ⚠️ **默认值必须和改之前像素一致**（13 / 12.5 / 11.5 / 11，字重 400/500），上面这些档位就是按旧值反推的。
  ⚠️ `.frow__name` 得**显式写 font-size** —— 它在 `<button>` 里，button 不继承父级的 font-size
- **左栏悬浮预览可在设置里关掉**（`左栏悬浮预览` 开关，默认开）：
  关掉时鼠标悬停完全不触发；如果关的瞬间面板正开着，会立刻收起
- **滚动条统一一套**：原来只有左栏和主区各写了一份 `::-webkit-scrollbar`，
  后来加的设置面板和悬浮面板就用系统默认样式（一粗一细、颜色也不同）。
  现在集中在文件开头定义一次（`.rail__list / .board / .panel / .fly__list`），
  谁要滚动谁把选择器加进那组规则即可
- **设置面板贴齿轮左下角**：右边缘跟齿轮对齐、顶边贴在它下方 8px，`max-height: min(70vh, 620px)`
  + 内部滚动（设置项以后变多、或小屏幕上都不会顶出屏幕）。
  ⚠️ 两个坑：① 面板必须挂在 `.page` **外面**（`.page` 有 `zoom/transform` 缩放，
    放里面的话 `position: fixed` 的坐标会被缩放，全错）；② 页面整体有 `--scale` 缩放，
    JS 里 setProperty 的 px 和屏幕 px 不是 1:1 → 先按 1:1 摆一次、量实际位置再按偏差修正一次
    （`right` 和 `top` 的修正符号相反：right 变大元素往左，top 变大元素往下）
- **悬浮面板是单例**（`flyBox`）：方向键切分组时是**换内容**，不再叠加（之前每块面板各有各的
  `box` 闭包，扫过几个分组就叠几层，阴影越叠越重）
- **去掉了「标题行数」设置**：实测确实生效（1/3/不限 = 21/64/85px），
  但书签标题大多本来就一行，调它几乎看不出区别 —— 用户 2026-10-14 拍板去掉，标题一律显示完整
